# Working in this repository

Follow the repository rules and applicable skills in [CLAUDE.md](CLAUDE.md).

## Read the graph first

For every coding task, bug investigation, review, or question about this repository,
consult the existing `graphify-out/graph.json` before searching or reading source code.
Follow [.claude/skills/graph-first/SKILL.md](.claude/skills/graph-first/SKILL.md).
This applies even when the user does not mention Graphify.

Start with a focused graph query and a budget of about 1,000 tokens. Then read only
the source files and line ranges needed to verify the result or make the change.
Keep the same order when another skill applies or work is delegated to an agent.

## Project memory

Read `PROJECTS.md` for the project the task concerns, then `CONTINUITY.md`. Follow
[.claude/skills/project-memory/SKILL.md](.claude/skills/project-memory/SKILL.md) for what to
read, how a decision is recorded and how to hand over. `PROJECTS.md` changes only on the
owner's request.
