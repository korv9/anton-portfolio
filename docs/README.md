# Documentation

One document per topic. Each one describes the system as it is; finished plans and one-off
reviews are removed once their content is in the document that owns the topic, and Git history
keeps them. Documents are in English or Swedish, whichever they were written in.

The repository overview is in the [root README](../README.md), the platform's layers and
directories in [platform/README.md](../platform/README.md), and the ML layer in
[ml/README.md](../ml/README.md).
